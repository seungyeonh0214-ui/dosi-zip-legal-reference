## 핵심 근거

**「재해취약성분석」은 법정 의무 절차입니다.**

> **국토계획법 제20조제2항** — *"기초조사의 내용에 토지적성평가와 **재해 취약성에 관한 분석**을 포함하여야 한다"*
> **제27조제3항** — 도시·군관리계획 입안 기초조사에도 동일 의무

따라서 이 과제는 새 지표를 발명하는 것이 아니라 **이미 존재하는 법정 절차를 데이터로 구현**하는 것입니다.

**공원은 재해저감 수단으로 명시되어 있습니다.**

> 지침 4-1-3.(1)마 — *"피해 저감을 위한 **공원, 녹지 등 도시계획 측면의 완충공간 입지계획** 고려"*

## 법령 조사 방법 (4단계)

모든 법령은 아래 절차로 확인했습니다.

1. **법령 찾기** — 정확한 법령명과 최신 개정 확인
2. **식별자 확인** — 법령ID, MST, 시행일, 소관부처
3. **조문 조회** — 필요한 조문 원문 확보
4. **시점 기록** — 시행일과 조회일을 함께 기록

### 식별자 주의

`korean-law` MCP가 반환하는 `statute:NNNNNN`은 **법령ID가 아니라 MST(법령일련번호)** 입니다.
law.go.kr 상세 URL의 `lsiSeq`와 같은 값이며, 법령ID(`lsId`)는 별도입니다.

```
국토의 계획 및 이용에 관한 법률
  법령ID  009294
  MST     284013   ← MCP의 statute:284013
  원문    https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=284013
```

**인용 표기 권장형**

```
국토의 계획 및 이용에 관한 법률 제20조제2항
(법령ID 009294 / MST 284013, 시행 2026-07-01, 조회 2026-09-21)
```

### 조례는 절차가 다릅니다

조례에는 **법령ID·MST가 없고**, 2단계가 식별자 확인이 아니라 **조문 번호 확인**입니다.
**지자체마다 조문 번호가 다르기** 때문입니다.

| 조례 | 제61조의 내용 |
|---|---|
| 천안시 도시계획 조례 | 용도지역의 **변경** |
| 평택시 도시계획 조례 | 용도지역안에서의 **용적률** |

다른 지역 사례의 조문 번호를 그대로 옮기면 틀린 인용이 됩니다.

```
평택시 도시계획 조례 제20조제1항제2호
(경기도평택시조례 제2630호, 시행 2026-05-18, 조회 2026-09-21)
```
